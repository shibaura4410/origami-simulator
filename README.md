# おりがみ 展開図シミュレーター

展開図に山折り・谷折りの線を引くと、紙が 3D で折りたたまれる、ブラウザで動く折り紙シミュレーターです。

## できること

- 展開図の編集(線を引く・点を打つ・選択・反選択・消しゴム・戻す/やり直す・拡大縮小)
- 線ごとの折り角の指定、吸着(等分点・交点)、角度の刻み(15°・22.5°・30°・45°)
- かたい紙(面を曲げない)としての折りたたみと、折りの進みスライダー
- 平らにたためない頂点のチェック(前川定理・川崎定理・大小大の法則)
- お手本: 半分、三角、ざぶとん、じゃばら、風船の基本形、正方基本形、ミウラ折り(列・行・角度を指定)
- SVG・FOLD の読み込みと保存(Origami Simulator と同じ色の決まり)
- Three.js による 3D 表示(影・折り線の表示、紙の表裏の色の変更)
- 全画面表示

## 使い方

`index.html` をブラウザで開くだけで動きます(3D 表示に Three.js を CDN から読み込みます)。

## おまけ: 包丁研ぎ道場

[`knife/index.html`](knife/index.html) は、砥石で包丁を研ぐブラウザゲームです(外部ライブラリなしで動きます)。

- 包丁を左右にドラッグして研ぎ、上下に動かして刃元〜切っ先の研ぐ場所を変える
- 刃の角度を 15° 前後に保つ(手がぶれるので ↑↓・ホイール・スライダーで直す)。立てすぎると刃が丸まり、寝かせすぎると刃の面にキズが入る
- 研いだ面の反対に出る「かえり」を、裏返して取る
- 荒砥 #220(刃こぼれ直し)→ 中砥 #1000 → 仕上砥 #6000 と進み、乾いたら水をかける
- 最後にトマトを試し切りして、切れ味・ムラ・キズ・時間から段位を判定(難易度 3 段階、自己ベストを保存)
