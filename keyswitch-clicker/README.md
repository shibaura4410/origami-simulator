# キースイッチ・クラッシャー

キーボードを 1 台ずつ壊していく、ブラウザで動くクリッカーゲームです。

## 遊び方

- キーは A→Z、つづいて 1→0 の順に 36 個並びます。クリック・タップのほか、手元のキーボードを叩いても壊せます。
- 与えたダメージがそのままスクラップになります。スクラップで工具・自動破壊・1 回かぎりの強化(工具の効果 2 倍など)を買います。
- 最初に使えるのは青軸だけです。キーボードを 1 台壊しきるたびに、赤軸・茶軸などほかの軸が 1 つ手に入り、選んで替えられます(違いは打鍵音と軸の色だけ)。
- 実績が 23 個あります。進み具合はブラウザに保存されます。

## 使い方

`index.html` をブラウザで開くだけで動きます。外部のライブラリや通信は使わず、このフォルダだけで完結しています。
